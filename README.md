# Order Management System

Бэкенд-сервис управления заказами на Go. Умеет регистрировать и авторизовать пользователей через JWT, работать с товарами и остатками на складе, создавать заказы в транзакциях и кэшировать список товаров в Redis.

## Что внутри
- **Авторизация:** регистрация, вход и выдача JWT-токенов.
- **Товары и кэш:** получение списка товаров через Redis (с TTL 5 минут и очисткой кэша при создании товара, изменении остатков или оформлении заказа).
- **Заказы:** создание заказа внутри транзакции PostgreSQL с проверкой остатков и блокировкой строк (`FOR UPDATE`), а также просмотр заказов пользователя.
- **Запуск и остановка:** работа через Docker Compose и завершение сервера (`graceful shutdown`) при остановке.

## Стек
- Go (`net/http`)
- PostgreSQL (`pgxpool`)
- Redis
- Docker и Docker Compose

## Как запустить

1. Склонируй репозиторий:
git clone https://github.com/SherizatM/OrdersSystemGolang.git
cd OrdersSystemGolang


2. Запусти базу, Redis и само приложение одной командой:
docker compose up --build

3. Если таблицы ещё не созданы, примени SQL-файлы из папки `migrations/` к базе `orders_db`.

4. Проверяй запросы на `http://localhost:8080`. Чтобы остановить всё, нажми `Ctrl+C` или выполни:
docker compose down

## Основные эндпоинты
- `POST /auth/sign-up` — регистрация нового пользователя
- `POST /auth/sign-in` — вход и получение JWT-токена
- `GET /products` — список товаров (с кэшированием в Redis)
- `POST /products` — создание товара и сброс кэша
- `PATCH /products/{id}/stock` — обновление остатка товара и сброс кэша
- `POST /orders` — создание заказа в транзакции с проверкой остатков
- `GET /orders` — список заказов текущего пользователя
